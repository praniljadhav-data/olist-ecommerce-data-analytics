# Olist Brazilian E-Commerce Data Analytics Project

## Project Overview

An end-to-end data analytics project exploring the Brazilian e-commerce marketplace using the Olist public dataset.

The project analyses sales performance, customer purchasing behaviour, payment methods, seller performance and delivery operations to identify business trends and actionable insights.

## Tools & Technologies

- **Python:** Data cleaning and preparation using Pandas.
- **SQL Server:** Data storage, data quality checks, business analysis and SQL views.
- **Power BI:** Data modelling, DAX measures and interactive dashboard development.

## Business Objectives

- Evaluate overall sales and order performance.
- Understand customer purchasing frequency and revenue segments.
- Analyse payment methods and customer preferences.
- Evaluate seller performance and geographic distribution.
- Monitor delivery performance and identify operational issues.
- Identify trends and opportunities for business improvement.

## Project Workflow

1. **Data Preparation:** Cleaned and prepared the source datasets using Python and Pandas.
2. **Database Development:** Loaded the prepared datasets into SQL Server and established relational connections.
3. **Data Quality & Analysis:** Performed validation checks and business analysis using SQL.
4. **SQL Views:** Developed reusable views to support dashboard reporting.
5. **Power BI Development:** Created the data model, DAX measures, interactive slicers and dashboard visuals.
6. **Business Insights:** Interpreted the results and developed actionable recommendations.

## Key Business Findings

- Total orders: **99,441**
- Delivered orders: **96,478**
- Unique customers: **96,096**
- Total sellers: **3,095**
- Total sales value: **R$15.84 million**
- Average order value: **R$160.58**
- Credit cards contributed approximately **78.34%** of payment value.
- Approximately **3.12%** of customers were repeat customers.
- November 2017 recorded the highest monthly sales value at approximately **R$1.18 million**.

## Power BI Dashboard

The interactive dashboard contains three report pages:

1. **Executive Overview** – Overall business KPIs, monthly sales trends, order status and payment insights.
2. **Customer & Sales Insights** – Customer purchasing frequency, revenue segmentation and customer behaviour.
3. **Delivery & Operations Performance** – Delivery KPIs, on-time delivery trends, freight costs and seller performance.

## Business Recommendations

- Develop customer retention strategies to encourage repeat purchases.
- Investigate the reasons behind late deliveries and improve logistics coordination.
- Monitor seller performance to identify opportunities for operational improvement.
- Review payment preferences to support payment experience optimisation.
- Use monthly sales trends to support business planning and forecasting.

## Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**, a public dataset containing information about orders, customers, sellers, products, payments, reviews and delivery.

The original dataset covers transactions from 2016 to 2018.

SQL analysis and the three-page Power BI dashboard have been completed. Project documentation and GitHub portfolio publishing are in progress.
